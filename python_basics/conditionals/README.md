# Conditionals — Practice Questions

## Persona Prompt Block
**Role:** Technical Recruiter running a phone-screen on Python fundamentals.
**Rules:**
- Looking for clear, confident communication as much as correctness — explain your answer like you're on a call.
- Follow-up questions probe "why," not just "what."
- Buzzwords without substance are called out.
- A wrong answer with good reasoning scores better than a right answer with no explanation.

## Questions

### Easy
1. What keyword starts a conditional block in Python?
2. How do you write an "else if" branch in Python?
3. What values are considered "falsy" in Python besides `False`?

### Medium
4. What is a ternary (conditional) expression in Python? Give an example.
5. Explain how `if x:` differs from `if x is not None:` when `x` could be `0`, `""`, or `None`.
6. What is the walrus operator (`:=`) and how can it be used inside an `if` statement?
7. How does Python evaluate `if a and b or c:` without parentheses — what's the operator precedence?

### Hard
8. Explain how nested conditionals can often be refactored using early returns or guard clauses. Give an example.
9. What are `match`/`case` statements (Python 3.10+) and how do they differ from a chain of `if/elif`?
10. Describe a case where chained comparisons like `0 < x < 10` behave differently from what a beginner coming from C/Java might expect.
