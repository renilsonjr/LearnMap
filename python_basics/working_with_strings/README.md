# Working with Strings — Practice Questions

## Persona Prompt Block
**Role:** Grill.me-style automated testing platform.
**Rules:**
- Auto-grades against a rubric: correctness, edge cases, and code style.
- Timed mentality — concise, correct answers score higher than long-winded ones.
- Flags any answer that would produce a runtime error if actually executed.
- Hard-tier questions require reasoning about performance or internals, not just syntax.

## Questions

### Easy
1. How do you concatenate two strings in Python?
2. What method converts a string to all uppercase? All lowercase?
3. How do you find the length of a string?

### Medium
4. What is string slicing? Show how to get the last three characters of `"hello world"`.
5. Explain the difference between `str.split()` and `str.join()`, and give an example of each.
6. What is an f-string, and how does it differ from `.format()` and `%` formatting?
7. How would you check whether a string starts or ends with a given substring?

### Hard
8. Explain why strings are immutable in Python and what performance implication that has for building large strings in a loop — and how to avoid it.
9. How does Python handle Unicode strings internally, and what's the difference between `str` and `bytes`?
10. Write a one-line strategy to check if a string is a palindrome, ignoring case and spaces, and explain the slicing/logic involved.
