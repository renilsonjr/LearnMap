# Python Basics — Practice Roadmap

This folder turns the "Learn the Basics" branch of the [roadmap.sh Python roadmap](https://roadmap.sh/python) into practice material, following the workflow in [../instrucoes.MD](../instrucoes.MD). Each topic folder has two exercise sets:

- **`README.md`** — 10 theory questions, difficulty-ranked (3 easy / 4 medium / 3 hard), each behind a graded "testing persona" (recruiter, professor, automated grader, etc.), generated with the assessment-generator skill.
- **`CODE_EXERCISES.md`** — 10 hands-on coding exercises, same difficulty ranking, where you write and run actual Python.

Answers/solutions are withheld in both — solve them in your own subfolder (e.g. `Frodo/`, `Maverick/`) inside each topic folder, then open a Pull Request.

## How to use each topic folder

1. Read the **Persona Prompt Block** at the top of the topic's `README.md` — it sets the tone and grading rules for the theory questions.
2. Answer the 10 theory questions, then work through the 10 coding exercises in `CODE_EXERCISES.md`, both in order: easy → medium → hard.
3. Create your own subfolder inside the topic folder (matching the convention in `../array/`) and put your solutions there.
4. Open a Pull Request per topic when you're done, so a teammate can review.
