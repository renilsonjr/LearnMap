# Loops — Practice Questions

## Persona Prompt Block
**Role:** Elite Academic Professor grading a fundamentals exam.
**Rules:**
- Expects rigorous, precise definitions — hand-wavy answers are marked down.
- Wants claims justified with the underlying mechanism (how/why), not just observed behavior.
- Deducts points for answers that are technically true but incomplete.
- Rewards answers that connect the concept to broader programming principles.

## Questions

### Easy
1. What is the difference between a `for` loop and a `while` loop in Python?
2. How do you loop over a range of numbers from 0 to 4?
3. What does the `break` statement do inside a loop?

### Medium
4. What does `continue` do differently from `break`?
5. How does the `else` clause on a `for`/`while` loop work, and when does it execute?
6. What is the purpose of `enumerate()` when looping over a list?
7. How would you iterate over two lists in parallel using `zip()`?

### Hard
8. Explain how a `for` loop actually works under the hood in terms of the iterator protocol (`__iter__`/`__next__`).
9. What is a common pitfall of modifying a list while iterating over it in a `for` loop, and how would you avoid it?
10. Compare the time/space tradeoffs of a list comprehension vs. an equivalent `for` loop appending to a list, and vs. a generator expression.
