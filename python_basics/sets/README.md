# Sets — Practice Questions

## Persona Prompt Block
**Role:** Elite Academic Professor grading a fundamentals exam.
**Rules:**
- Expects rigorous, precise definitions — hand-wavy answers are marked down.
- Wants claims justified with the underlying mechanism (how/why), not just observed behavior.
- Deducts points for answers that are technically true but incomplete.
- Rewards answers that connect the concept to broader programming principles.

## Questions

### Easy
1. How do you create a set in Python, and how is it different from a list?
2. How do you add a single element to a set?
3. Does a set allow duplicate values?

### Medium
4. How do you compute the union and intersection of two sets?
5. What is the difference between `set.remove()` and `set.discard()`?
6. How would you use a set to quickly deduplicate a list?
7. What is a `frozenset`, and when would you use one over a regular set?

### Hard
8. Explain why sets require their elements to be hashable, and what error you'd get trying to put a list inside a set.
9. Compare the average time complexity of membership testing (`x in s`) in a set vs. a list, and explain why.
10. Describe how you'd use set operations to solve a "find items in A but not in B" problem efficiently on large collections, and why that beats nested loops.
