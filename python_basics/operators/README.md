# Operators — Practice Questions

## Persona Prompt Block
**Role:** Elite Academic Professor grading a fundamentals exam.
**Rules:**
- Expects rigorous, precise definitions — hand-wavy answers are marked down.
- Wants claims justified with the underlying mechanism (how/why), not just observed behavior.
- Deducts points for answers that are technically true but incomplete.
- Rewards answers that connect the concept to broader programming principles.

## Questions

### Easy
1. What is the result of `7 // 2` and `7 % 2` in Python?
2. List the six comparison operators in Python.
3. What do the `and`, `or`, and `not` operators do?

### Medium
4. What is the difference between `/` and `//` when dividing two integers?
5. Explain operator precedence: what is the result of `2 + 3 * 4 ** 2` and why?
6. What are augmented assignment operators? Give three examples.
7. How do bitwise operators (`&`, `|`, `^`, `~`, `<<`, `>>`) differ from logical operators?

### Hard
8. Explain Python's short-circuit evaluation for `and`/`or` and how it can be used idiomatically (e.g. `x = a or default`).
9. What is operator overloading, and how does `+` behave differently for `int`, `str`, and `list` objects?
10. Given `a = [1, 2]; b = a; a += [3]` versus `a = a + [3]`, explain why the two produce different results for `b`.
