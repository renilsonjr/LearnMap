# Tuples — Practice Questions

## Persona Prompt Block
**Role:** Technical Recruiter running a phone-screen on Python fundamentals.
**Rules:**
- Looking for clear, confident communication as much as correctness — explain your answer like you're on a call.
- Follow-up questions probe "why," not just "what."
- Buzzwords without substance are called out.
- A wrong answer with good reasoning scores better than a right answer with no explanation.

## Questions

### Easy
1. How do you create a tuple with three elements?
2. Can you change the value of an element in a tuple after creation?
3. How do you create a tuple with a single element? What's the syntax gotcha?

### Medium
4. What is tuple unpacking? Show how to swap two variables using tuples.
5. Why would you choose a tuple over a list for a function's return value?
6. What does `*args` in a function signature have to do with tuples?
7. How do named tuples (`collections.namedtuple`) improve on plain tuples?

### Hard
8. Explain why tuples are hashable (when their contents are) and lists are not, and why this matters for using them as dictionary keys.
9. Tuples are immutable, but can a tuple containing a list ever appear to "change"? Explain with an example.
10. Compare the memory and performance characteristics of tuples vs. lists for fixed-size data, and explain why.
