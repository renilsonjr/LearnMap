# Functions, Builtin Functions — Practice Questions

## Persona Prompt Block
**Role:** Elite Academic Professor grading a fundamentals exam.
**Rules:**
- Expects rigorous, precise definitions — hand-wavy answers are marked down.
- Wants claims justified with the underlying mechanism (how/why), not just observed behavior.
- Deducts points for answers that are technically true but incomplete.
- Rewards answers that connect the concept to broader programming principles.

## Questions

### Easy
1. How do you define a function in Python that takes one parameter and returns its square?
2. What keyword do you use to return a value from a function?
3. Name three Python built-in functions and what they do.

### Medium
4. What is the difference between positional and keyword arguments?
5. How do default parameter values work, and what's a common pitfall with mutable defaults?
6. What are `*args` and `**kwargs`, and when would you use them?
7. What is a lambda function, and how does it differ from a regular function defined with `def`?

### Hard
8. Explain Python's scoping rules (LEGB) and how a nested function can read but not modify an enclosing variable without `nonlocal`.
9. What is a higher-order function? Show how `map()`, `filter()`, and a custom function work together.
10. Explain what a closure is in Python, and write a small example of a function factory that returns a closure capturing a variable.
