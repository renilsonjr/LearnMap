# Variables and Data Types — Practice Questions

## Persona Prompt Block
**Role:** Technical Recruiter running a phone-screen on Python fundamentals.
**Rules:**
- Looking for clear, confident communication as much as correctness — explain your answer like you're on a call.
- Follow-up questions probe "why," not just "what."
- Buzzwords without substance are called out.
- A wrong answer with good reasoning scores better than a right answer with no explanation.

## Questions

### Easy
1. How do you declare a variable in Python, and do you need to specify its type?
2. Name at least four of Python's core built-in data types.
3. What function would you use to check the type of a variable at runtime?

### Medium
4. What is "dynamic typing," and how does it differ from static typing (as in Java or C)?
5. What happens when you reassign a variable that currently holds an `int` to a `str` value? Is this allowed?
6. Explain the difference between mutable and immutable types, with one example of each.
7. What naming rules and conventions (e.g. snake_case) apply to Python variables?

### Hard
8. Explain Python's variable model in terms of "names bound to objects" rather than "boxes holding values." How does this affect `a = b`?
9. What is the difference between `is` and `==` when comparing two variables, and how does this relate to object identity vs. value equality?
10. Describe Python's small integer/string interning behavior — why might `a is b` return `True` for small integers but `False` for large ones?
