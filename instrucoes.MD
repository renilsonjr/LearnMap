Estruturacao do projeto e pastas
1 - Peca ajuda da IA pra estrura: Use a IA para ajudar a montar uma arvore de pastas focada em estruturas de dados e algoritimos, de forma agnostica (sem estar presa a uma linguagem especifica) Exemplos de pasta que devem existir: array, hash_map, bubble_sort, pesquisa_binaria, etc.
2 - Crie o README geral: Faca um arquivo readm.md principal bem grande na raiz do projeto, explicando como tudo funciona e como fazer as tarefas.
3 - Crie a subpasta "frodo": dentro de cada uma das pastas de assunto (ex dentro de array), crie uma pasta especifica chamada frodo. E dentro dessa pasta que vc vai colocar os seus scripts de resolucao.

GERACAO DE QUESTOES E PRATICA
1 - Gere os desafios com a IA: Para cada assunto, crie um prompt para a IA( ex: pedindo para ela agir como uma plataforma de testes tipo grill.me ou um recrutador) e peca para gerar cerca de 10 perguntas ranqueadas em niveis: facil, medio e dificil.
2 - Documente as questoes: Coloque as 10 perguntas geradas pela IA dentro de um README.md especifico daquela pasta de assunto.
3 - Resolva e abra o pull request: Escreva o codigo resolvendo as questoes dentro da sua subpasta frodo. Quando terminar um assunto, abra um Pull Request para que seu colega possa visualizar o que vc fez e revisar o codigo.
