# CTU Practice — Original Exercises Inspired by Coursework

This folder is **separate from `python_basics/`** on purpose: it's extra practice inspired by the topics covered week-by-week in the CTU intro Python course. Each week has a theory set and a code set in the assessment-generator skill's format (persona + 10 ranked items: 3 easy / 4 medium / 3 hard).

**Important:** these are original exercises with original scenarios — not the actual CTU/zyBooks assignment text, and not copies of any submitted solution. Only the underlying skill being practiced (e.g. "if/elif/else with multiple branches," "type conversion," "nested conditionals") is the same. The real coursework file stays local-only and gitignored (`CTU_CODE_EXCERCISES*` / `ctu_code_exercises*` in `.gitignore`) — nothing from it is reproduced here.

## Weeks

1. Week 1 — Fundamentals: [theory](week1/README.md) · [code](week1/CODE_EXERCISES.md). Print/input, type conversion, expressions, float formatting, debugging syntax and logic errors.
2. Week 2 — Conditionals: [theory](week2/README.md) · [code](week2/CODE_EXERCISES.md). If/elif/else, boolean logic, nested ifs, indentation, dictionary lookups.
3. Week 3 — Lists, Tuples, and Loops: [theory](week3/README.md) · [code](week3/CODE_EXERCISES.md). Lists and tuples, `while`/`for` loops, sentinel values, nested loops, looping over strings and dictionaries.
4. Week 4 — Functions: [theory](week4/README.md) · [code](week4/CODE_EXERCISES.md). Defining functions, parameters, `return`, one function calling another, missing-return bugs, returning multiple values, variable scope, the `if __name__ == "__main__":` guard.

Further weeks get added here as you have them — same format each time.

## How to use

Same as `python_basics/`: work through easy → medium → hard. Explain the theory questions in your own words, then write real runnable scripts for the code exercises. Put your work in your own subfolder (e.g. `Frodo/`). No answer key is included.
