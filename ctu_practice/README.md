# CTU Practice — Original Exercises Inspired by Coursework

This folder is **separate from `python_basics/`** on purpose: it's extra practice inspired by the topics covered week-by-week in the CTU intro Python course, generated with the assessment-generator skill's format (persona + 10 ranked exercises: 3 easy / 4 medium / 3 hard).

**Important:** these are original exercises with original scenarios — not the actual CTU/zyBooks assignment text, and not copies of any submitted solution. Only the underlying skill being practiced (e.g. "if/elif/else with multiple branches," "type conversion," "nested conditionals") is the same. The real coursework file stays local-only and gitignored (`CTU_CODE_EXCERCISES*` / `ctu_code_exercises*` in `.gitignore`) — nothing from it is reproduced here.

## Weeks

1. [Week 1 — Fundamentals](week1/CODE_EXERCISES.md): print/input, type conversion, expressions, float formatting, debugging syntax and logic errors.
2. [Week 2 — Conditionals](week2/CODE_EXERCISES.md): if/elif/else, boolean logic, nested ifs, indentation, dictionary lookups.

More weeks get added here as you go (Week 3, Week 4, ...) — same format each time.

## How to use

Same as `python_basics/`: work through easy → medium → hard, write real runnable scripts, put solutions in your own subfolder (e.g. `Frodo/`), and this is for solo practice — no answer key is included.
